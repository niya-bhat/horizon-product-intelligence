# Horizon — AI-Powered Product Intelligence

Horizon is a noncommercial educational prototype being developed as part of a university class project at Purdue University.

The application will allow users to search for products across different industries and automatically aggregate relevant public discussions, customer feedback, competitor updates, and news articles.

## Planned Features

- Search for information about arbitrary consumer or software products.
- Retrieve relevant public posts and comments using approved APIs.
- Identify customer complaints, feature requests, product comparisons, and workarounds.
- Group similar discussions into recurring themes using AI.
- Generate concise, source-backed product intelligence briefings.
- Provide direct links to original discussions.

## Reddit API Integration

Horizon intends to use Reddit's Data API for read-only retrieval of public product-related posts and comments.

The application will not post, comment, vote, message users, or profile individual Reddit accounts. Reddit content will be used for classification and summarization, not for training AI models.

The project is currently in early development. Reddit API integration is planned and pending authorization.

## Project Status

Educational prototype in development. Not publicly launched or monetized.
